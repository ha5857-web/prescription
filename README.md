# 진료 차팅·처방 도구

증상을 체크하면 EMR 차트와 오더가 함께 만들어지는 외래 진료 보조 웹앱입니다. 서버 없이 HTML 파일만으로 동작하므로 GitHub Pages에 그대로 올리면 됩니다.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 첫 화면 (네 도구로 가는 링크) |
| `peds.html` | 소아 차팅·처방 — 증상 체크 → EMR 양식 v2 + 체중별 블록 오더 |
| `adult.html` | 성인 차팅·처방 + 고찰 — 6개 주호소, 다빈도 21개 질환 |
| `calc.html` | 소아 용량계산기 |
| `drill.html` | 소아 증례훈련 |
| `.nojekyll` | GitHub Pages가 파일을 가공하지 않게 하는 빈 파일 (지우지 마세요) |

각 HTML 파일은 혼자서도 동작합니다. 글꼴만 Google Fonts에서 불러오고, 그 밖의 외부 서버는 쓰지 않습니다.

## GitHub Pages에 올리기 (처음 한 번)

1. GitHub에서 **New repository**를 누르고 이름을 정합니다 (예: `rx-tools`). **Public**으로 만듭니다.
   - 무료 계정은 공개 저장소에서만 Pages를 쓸 수 있습니다. 공개해도 환자 정보는 들어 있지 않습니다.
2. 저장소 화면에서 **Add file → Upload files**를 누르고, 이 폴더 안의 파일을 **전부** 끌어다 놓습니다 (`.nojekyll` 포함). **Commit changes**를 누릅니다.
   - 숨김 파일(`.nojekyll`)이 끌어지지 않으면 **Add file → Create new file**에서 이름을 `.nojekyll`로, 내용은 비운 채 저장해도 됩니다.
3. **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 **main / (root)**로 고르고 **Save**를 누릅니다.
4. 1–2분 뒤 `https://<GitHub 아이디>.github.io/<저장소 이름>/` 으로 열립니다.

## 고칠 때

- 바뀐 HTML 파일만 같은 이름으로 다시 **Upload files** 하면 덮어써집니다. 1–2분 뒤 반영됩니다.
- 브라우저가 이전 화면을 보여주면 새로고침(Ctrl+Shift+R / Cmd+Shift+R)을 합니다.

## 공통 규칙

- 오더 표기: `1일 총량/횟수/일수`. 예를 들어 `3/3/3`은 하루 3(알·포·단위)을 3회로 나눠 3일입니다. 외용·흡입·분무제는 `1통/1/1`로 두고 용법은 메모에 적었습니다.
- 처방 제약: 의원에서 세프트리악손 주사 불가, 아목시실린 단독 미보유 (성인 앱 설정에서 바꿀 수 있음).
- 근거 표시: `[G]` 진료지침 · `[E]` 연구 근거 · `[P]` 실무 경험 · `[확인]` 보유 제품·허가 확인 필요.
- 저장: 환자 정보는 저장하지 않습니다. 브라우저 `localStorage`에는 농도·재고·기본 일수 같은 설정만 남습니다.
